# Code of Conduct

## Our standard

Hermes Prompt Controls welcomes careful technical disagreement and evidence about compatibility.
Participants must communicate respectfully, stay within the project's public scope and protect
private prompt data.

Expected behavior includes:

- criticizing ideas, code and evidence rather than people;
- using fictional, minimized reproductions;
- respecting licenses, privacy and coordinated disclosure;
- accepting moderation decisions without retaliation.

Unacceptable behavior includes:

- harassment, threats, discriminatory language or unwanted sexual attention;
- publishing personal data, credentials, private prompts, mappings, session state or exploit details;
- spam, impersonation, sustained disruption or retaliation;
- using project channels to coordinate unauthorized access or real-world harm.

## Scope and enforcement

This code applies to issues, pull requests, reviews, commits and other project spaces, including
public representation of the project.

Maintainers may edit or hide content, lock a conversation, reject or close a contribution, limit
participation or block an account. They will consider severity, context, repetition and the safety
of affected people.

Report visible violations with GitHub's controls on the relevant content. For confidential content,
use GitHub's **Report content** flow rather than publishing it in an issue. Private Vulnerability
Reporting is reserved for security vulnerabilities in this plugin.
