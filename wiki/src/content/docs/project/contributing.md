Hermes Prompt Controls accepts focused issues and pull requests during pre-release development.
Search existing reports and use the structured GitHub forms.

A useful compatibility report includes:

- plugin commit and Hermes Agent version or commit;
- Python and operating-system versions;
- public host APIs and request modes involved;
- a minimal fictional request and configuration;
- expected and observed behavior;
- privacy, fail-open and cache effects.

Do not include real directives, mappings, prompt content, profiles, prefills, session IDs,
credentials, endpoints, configuration or logs.

Read [`CONTRIBUTING.md`](https://github.com/Yivas/hermes-prompt-controls/blob/main/CONTRIBUTING.md),
[`SECURITY.md`](https://github.com/Yivas/hermes-prompt-controls/blob/main/SECURITY.md) and the
[Code of Conduct](https://github.com/Yivas/hermes-prompt-controls/blob/main/CODE_OF_CONDUCT.md)
before participating.
